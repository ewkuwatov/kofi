# KOFI / 02

Готовый сайт городской кофейни на Laravel 13: меню с категориями, корзина, предзаказ на самовывоз, подписка на новости и закрытая страница команды со списком заказов и сменой статусов.

## Что внутри

- Главная страница с историей кофейни, часами и адресом.
- Меню, категории напитков и выпечки, карточки позиций.
- Корзина на сессиях и форма предзаказа с проверкой данных.
- Сохранение заказов, контактных данных и строк заказа в MySQL.
- Уникальная страница подтверждения заказа.
- Подписка на новости с защитой от дублирующего email.
- Страница `/studio` под HTTP Basic Auth: просмотр заказов и обновление статусов.
- Адаптивная вёрстка, HTML/CSS/JS без сборки Node/Vite.

## Развёртывание в Plesk

Этот проект рассчитан на PHP 8.4 и Laravel 13. Plesk на скриншоте уже создал Laravel-приложение, поэтому добавьте содержимое этой папки в связанный Git-репозиторий **в корень репозитория**: на одном уровне должны оказаться `composer.json`, `artisan`, `bootstrap/`, `config/`, `public/`, `resources/`, `routes/` и `database/`. Не отправляйте родительскую папку `outputs/kofi-02` целиком так, чтобы `composer.json` оказался на уровень ниже.

Затем в панели:

1. Для домена выберите PHP **8.4.27**.
2. Во вкладке **Развертывание** запустите deploy последнего коммита.
3. Во вкладке **Composer** установите зависимости из `composer.json`.
4. Укажите `public/` как Document root приложения.
5. Создайте MySQL-базу и пользователя в Plesk. Во вкладке переменных окружения заполните параметры из `.env.example`: `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL`, `DB_HOST`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`, `STUDIO_USER`, `STUDIO_PASSWORD`. Пароль страницы команды задайте длинным случайным значением.
6. Во вкладке **Artisan** выполните по очереди:

   ```text
   key:generate --force
   migrate --force
   db:seed --force
   optimize:clear
   ```

7. Проверьте права записи для `storage/` и `bootstrap/cache/`, затем откройте домен по HTTPS.

Страница меню `/menu`, корзина `/cart`, закрытая панель команды `/studio`. Для `/studio` браузер попросит логин и пароль из `STUDIO_USER` и `STUDIO_PASSWORD`.

## Настройки перед публикацией

- Замените адрес кофейни, телефон, название улицы и ссылку карты в `resources/views/layouts/app.blade.php` и `resources/views/home.blade.php`.
- Замените демонстрационные фотографии Unsplash на собственные, если хотите хранить медиа на своём хостинге.
- В меню указано, что заказ оплачивается на кассе. Интернет-эквайринг не подключён.
- Не добавляйте файл `.env` с паролями и ключами в Git. В репозитории хранится только `.env.example`.

В рабочей среде создания проекта PHP и Composer не установлены; зависимости здесь не скачаны и запуск Laravel локально не выполнялся. Установка зависимостей и Artisan-команды предусмотрены через Plesk.
